One original painfully honest out-of-office auto-reply, written to `/output/entry.txt` — honest enough to sting, polite enough to survive being forwarded to a manager.

The program writes exactly one line — the reply that admits the private truth:

> I'm away and, to be honest, not checking email is a lie: I'm reading every message and replying to none of them until I'm back, so please bear with me.

## Run it

```sh
node main.ts
```
